Trabajos/Proyectos Realizados
HTML y CSS

• Salón de la Fama LHP

Herramientas: HTML y CSS

Necesidad: Transicionar el historial de campeones y el control de torneos de un formato Excel a una plataforma web más accesible y visual.

Descripción: Desarrollo de una interfaz gráfica puramente informativa maquetada con HTML y CSS. Para optimizar los tiempos de carga y evitar la saturación visual del usuario, el contenido se estructuró dividiéndolo en múltiples archivos HTML de navegación.


• Quiniela LHP

Herramientas: HTML, CSS, JavaScript con EmailJS

Necesidad: Para un torneo anual de 3 divisiones y aproximadamente 64 jugadores, se requería llevar el registro de pronósticos de cada encuentro. La plataforma que usaban (Facebook) no admitía tantas entradas, por lo que, tras ver mi trabajo en el Salón de la Fama, me buscaron para crear una alternativa.

Descripción: Se desarrolló la interfaz gráfica con HTML y CSS para los campos de entrada, así como las páginas de estadísticas y tablas de aciertos. Tras investigar métodos para el manejo de la información, se integró EmailJS, al concluir que era la opción más segura para los usuarios y muy eficiente en su versión gratuita.

Desafío: Dado que mi especialidad es UI/UX (Diseño de Interfaces), el mayor reto fue investigar cómo conectar los campos de entrada estáticos con el script que entrega EmailJS, logrando modificarlo con éxito para adaptarlo a la necesidad exacta de 32 partidos.


• CarGolf

Herramientas: HTML, CSS, JavaScript, EmailJS y Firebase

Necesidad: Crear una plataforma web para dar una presentación más formal y profesional al trabajo de mi padre en diversos entornos. El objetivo era tener un espacio centralizado que mostrara sus servicios y que a la vez contara con un sistema de registro de consultas organizado.

Descripción: Se maquetó una interfaz informativa y un formulario de consultas utilizando puramente HTML y CSS. Para la gestión de la información, escalé la solución utilizada en mi proyecto anterior: integré EmailJS para recibir alertas de contacto inmediatas, y lo enlacé en paralelo con Firestore (una base de datos NoSQL de Firebase) para tener un registro administrativo sólido. Adicionalmente, implementé un sistema de Login de Firebase para evitar consultas anónimas y proteger los datos de los usuarios.

Desafío: Fue mi primera vez trabajando con una base de datos. El mayor reto, dado mi enfoque en el diseño visual y mi nivel básico de JavaScript, fue investigar y lograr integrar dos scripts completamente distintos para que funcionaran en perfecta sincronía al mismo tiempo (uno enviando la alerta por EmailJS y otro registrando el dato en Firestore).


• Mi Perfil Social

Herramientas: HTML y CSS

Necesidad: Contar con un "lienzo" digital personal para documentar mi evolución técnica y volcar mi creatividad. El objetivo era diseñar un espacio que reflejara fielmente mi personalidad, mis gustos y los conocimientos que adquiero día con día.

Descripción: Una interfaz evolutiva maquetada puramente con HTML y CSS, sin depender de frameworks. Está diseñada con responsividad total para adaptarse a PC y dispositivos móviles. Como toque personal, integré un breve script para incorporar un reproductor multimedia que permite navegar por las pistas de mis artistas favoritos directamente en la página.

Enfoque: Más que un reto técnico, este proyecto fue un ejercicio de libertad creativa y orden. Mi objetivo principal fue mantener un código limpio, modular y puramente estructurado para asegurar que la interfaz pueda crecer y actualizarse fácilmente conforme adquiero nuevos conocimientos.
